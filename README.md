# وب‌سایت سه‌بعدی لنا بحری

این پروژه یک وب‌سایت استاتیک، راست‌چین و ریسپانسیو است و برای اجرا به نصب هیچ پکیجی نیاز ندارد.

## اجرای محلی

فایل `index.html` را با مرورگر باز کنید. برای تست بهتر می‌توانید پوشه را با یک وب‌سرور ساده اجرا کنید.

## آپلود روی هاست

تمام فایل‌ها و پوشه `assets` را داخل پوشه اصلی دامنه (معمولاً `public_html`) کپی کنید:

- `index.html`
- `style.css`
- `script.js`
- `portfolio.html`
- `about.html`
- `museum.css`
- `museum.js`
- `gallery-data.js`
- `assets/`

صفحهٔ `services.html` قیمت‌های خدمات را نمایش می‌دهد و هر خدمت را برای رزرو در فرم صفحهٔ اصلی از پیش انتخاب می‌کند. فرم رزرو، درخواست و عکس را در دیتابیس خصوصی D1 ثبت می‌کند؛ عکس‌ها حداکثر ۱٫۵ مگابایت هستند و فقط از پنل `admin.html` پس از ورود مدیر قابل مشاهده‌اند. پاک‌سازی پایگاه فعال با زمان‌بندی ساعتی پس از ۹۰ روز انجام می‌شود؛ نسخهٔ فنی بازیابی D1 ممکن است تا ۷ روز دیگر باقی بماند. واتساپ فقط پیش‌نویس پیام را باز می‌کند و مشتری باید ارسال نهایی را خودش تأیید کند؛ عکس نیز خودکار به واتساپ پیوست نمی‌شود.

## پنل رزرو Cloudflare

سایت عمومی روی GitHub Pages باقی می‌ماند و مسیر `https://lenabahri.ir/api/*` به Worker وصل می‌شود. برای راه‌اندازی بک‌اند، Cloudflare Wrangler را نصب/اجرا کنید و از پوشهٔ `cloudflare/booking-api`:

1. دیتابیس D1 با نام `lena-bookings` را بسازید و شناسهٔ آن را در `wrangler.toml` ثبت کنید.
2. با `npx wrangler d1 migrations apply lena-bookings --remote` ساختار دیتابیس را ایجاد کنید.
3. Worker را با `npx wrangler deploy` منتشر کنید؛ تا پیش از تنظیم secretها، API رزرو داده‌ای نمی‌پذیرد.
4. با `node scripts/set-secrets.mjs` رمز اولیه را در ترمینال مخفی، دو بار وارد کنید. ابزار رمز را با PBKDF2 هش می‌کند و فقط هش و کلیدهای تصادفی نشست/محدودسازی را با Wrangler به‌صورت secret می‌فرستد؛ رمز یا هش داخل مخزن ذخیره نمی‌شود.

عکس‌ها در همان ردیف خصوصی D1 به‌شکل BLOB نگه‌داری می‌شوند؛ بنابراین به اشتراک R2 و هزینهٔ آن نیاز نیست. برای سازگاری با سقف اندازهٔ ردیف D1، هر عکس باید حداکثر ۱٫۵ مگابایت باشد.

برای توسعهٔ محلی از `npm test` و `npm run check` استفاده کنید. `admin.html` عمداً در نقشهٔ سایت قرار نمی‌گیرد و دسترسی آن با نشست HttpOnly، Secure و SameSite محافظت می‌شود. تغییر وضعیت، جست‌وجو و مشاهدهٔ عکس فقط بعد از ورود انجام می‌شود.

## اضافه‌کردن نمونه‌کار و افتخار

اطلاعات گالری و افتخارات در فایل `gallery-data.js` قرار دارد:

- برای نمونه‌کار تازه، یک آیتم جدید به آرایه `projects` اضافه کنید.
- برای مقام یا مدرک تازه، یک آیتم جدید به آرایه `awards` اضافه کنید.
- تصویر جدید را داخل پوشه `assets` قرار دهید و نام آن را در فیلد `image` بنویسید.

## تصاویر واقعی

تصاویر ارسالی برای استفاده در وب بهینه و با نام‌های استاندارد در `assets/gallery` ذخیره شده‌اند:

- `awards`: هجده تصویر مدرک، جام و مدال
- `brand`: پرتره‌های WULOP 2024
- `people`: تصاویر رویدادها و دیدارهای حرفه‌ای
- `portfolio`: نمونه‌کارها و تصاویر قبل/بعد
- `clinic`: تصاویر محیط کار و اجرای استریل

فایل‌های اصلی پوشه Downloads تغییر یا حذف نشده‌اند.

## هویت بصری و فونت

- لوگوی رسمی در `assets/brand/logo-lb-optimized.png` قرار دارد.
- فونت لایسنس‌دار Anjoman Max با وزن‌های Regular، Medium و Bold از مسیر `assets/fonts` بارگذاری می‌شود.
- فونت‌ها به‌صورت محلی ارائه می‌شوند و سایت برای نمایش آن‌ها به سرویس خارجی وابسته نیست.

## گالری رویدادها
