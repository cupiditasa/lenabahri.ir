# وب‌سایت لنا بحری

وب‌سایت عمومی به‌صورت فایل‌های استاتیک ارائه می‌شود؛ درخواست‌های رزرو از API خصوصی Node.js روی VPS ایران به پایگاه SQLite خصوصی می‌رسند. دامنهٔ `lenabahri.ir` از Nginx روی همان VPS سرو می‌شود و GitHub مخزن کد است.

## اجرای محلی

فایل `index.html` را با مرورگر باز کنید. برای تست بهتر می‌توانید پوشه را با یک وب‌سرور ساده اجرا کنید.

## انتشار و زبان‌ها

صفحه‌های فارسی در ریشه و ترجمه‌های انگلیسی، عربی و چینی ساده‌شده در مسیرهای `/en/`، `/ar/` و `/zh/` قرار دارند. برای بازسازی نسخه‌های ترجمه‌شده از `node scripts/build-locales.mjs` استفاده کنید؛ `node scripts/build-locales.mjs --audit` پوشش ترجمه‌ها را بررسی می‌کند. انتشار عمومی با به‌روزرسانی نسخهٔ استاتیک زیر `/var/www/lenabahri/current` روی VPS انجام می‌شود.

## رزرو و پنل مدیریت

فرم رزرو با `POST /api/bookings` به API هم‌دامنه ارسال می‌شود و درخواست را در SQLite خصوصی VPS ثبت می‌کند. پس از ثبت موفق، کد پیگیری در همان صفحه نمایش داده می‌شود؛ فرم اطلاعات را به واتساپ نمی‌فرستد. مدیر از `admin.html` وارد می‌شود و می‌تواند درخواست‌ها را جست‌وجو، وضعیتشان را تغییر و عکس خصوصی را مشاهده کند. عکس حداکثر ۱٫۵ مگابایت است. پاک‌سازی خودکار داده‌های فعال پس از ۹۰ روز انجام می‌شود؛ نسخهٔ پشتیبان ممکن است تا ۷ روز دیگر باقی بماند. متغیرهای حساس API فقط در `/etc/lena-booking-api.env` روی سرور نگه‌داری می‌شوند و نباید وارد مخزن شوند.

API با سرویس `lena-booking-api` اجرا می‌شود؛ پایگاه داده در مسیر خصوصی `/var/lib/lena-booking-api` است و Nginx فقط `/api/*` را به سرویس محلی پروکسی می‌کند. برای توسعه و اعتبارسنجی از `npm test --prefix cloudflare/booking-api` و `npm run check --prefix cloudflare/booking-api` استفاده کنید. `admin.html` در نقشهٔ سایت قرار نمی‌گیرد و درخواست‌های مدیریتی به نشست امن نیاز دارند.

## اضافه‌کردن نمونه‌کار و افتخار

اطلاعات گالری و افتخارات در فایل `gallery-data.js` قرار دارد:

- برای نمونه‌کار تازه، یک آیتم جدید به آرایه `projects` اضافه کنید.
- برای مقام یا مدرک تازه، یک آیتم جدید به آرایه `awards` اضافه کنید.
- تصویر جدید را داخل پوشه `assets` قرار دهید و نام آن را در فیلد `image` بنویسید.

## تصاویر واقعی

تصاویر ارسالی برای استفاده در وب بهینه و با نام‌های استاندارد در `assets/gallery` ذخیره شده‌اند:

- `awards`: هجده تصویر مدرک، جام و مدال
- `brand`: پرتره‌های WULOP 2024
- `people`: تصاویر رویدادها و دیدارهای حرفه‌ای
- `portfolio`: نمونه‌کارها و تصاویر قبل/بعد
- `clinic`: تصاویر محیط کار و اجرای استریل

فایل‌های اصلی پوشه Downloads تغییر یا حذف نشده‌اند.

## هویت بصری و فونت

- لوگوی رسمی در `assets/brand/logo-lb-optimized.png` قرار دارد.
- فونت لایسنس‌دار Anjoman Max با وزن‌های Regular، Medium و Bold از مسیر `assets/fonts` بارگذاری می‌شود.
- فونت‌ها به‌صورت محلی ارائه می‌شوند و سایت برای نمایش آن‌ها به سرویس خارجی وابسته نیست.

## گالری رویدادها

گالری «رویدادها و دیدارهای حرفه‌ای» از موس، لمس، Drag، اسکرول افقی تاچ‌پد، چرخ موس و دکمه‌های قبلی/بعدی پشتیبانی می‌کند. تصاویر رویداد 01 و 09 بنا به درخواست از پروژه حذف شده‌اند.
